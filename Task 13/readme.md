# Employee Statistics Analysis Dashboard using Tableau Public

## Project Overview
This project focuses on analyzing an Employee Statistics dataset using Tableau Public. The objective is to explore employee data, identify important patterns, compare departments, and discover meaningful business insights through interactive visualization

**Dashboard Title:** Employee Statistics Analysis Dashboard

## Visualizations Created

### 1. Employee Count by Department – Bar Chart
- Displays the number of employees in each department.
- Identifies departments with the highest and lowest employee counts.
- Helps compare department-wise employee distribution.

### 2. Employee Joining Trend – Line Chart
- Shows employee joining patterns over time.
- Identifies months with higher and lower employee recruitment.
- Helps understand hiring trends.

### 3. Experience vs Performance – Scatter Plot
- Compares employee experience with performance scores.
- Helps identify relationships between experience and performance.
- Uses department and salary as additional visual details.

### 4. Department Satisfaction – Heat Map
- Compares average employee satisfaction across departments and cities.
- Highlights areas with higher and lower satisfaction levels.
- Helps identify employee satisfaction patterns.

### Filters Added
- Department
- City
- Gender
- Age

Users can select different filter values to explore and compare employee statistics.

## Key Findings
1. Identifies departments with the highest and lowest employee counts.
2. Highlights months with the highest employee recruitment.
3. Explores the relationship between employee experience and performance.
4. Identifies department and city combinations with higher employee satisfaction.

## Conclusion
The analysis helps understand employee distribution, recruitment trends, performance, and satisfaction. Tableau visualizations make the data easier to understand and support better business decision-making.

## Suggestions
- Improve recruitment planning.
- Provide employee training programs.
- Monitor employee performance regularly.
- Improve employee satisfaction through feedback and support.

## Recommendations
1. Focus on departments with higher recruitment needs.
2. Provide training to improve employee performance.
